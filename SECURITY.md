# Security policy

Please do not disclose vulnerability details in public issues or pull requests.

Use GitHub's **Report a vulnerability** option on this repository's Security tab when private reporting is available. If it is unavailable, open an issue requesting a private contact channel, without including vulnerability details or proof-of-concept code.

Include the affected version or commit, configuration, reproduction steps and impact in your private report. Issues in unmodified upstream code may also be reported through the [Tauri security policy](https://github.com/tauri-apps/plugins-workspace/security/policy).
